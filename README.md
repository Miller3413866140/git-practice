# git-practice

我的第一个 GitHub 仓库，用来练习 Git 的完整工作流。

## 这个仓库是什么

从零开始走一遍：本地初始化 → 提交 → 关联远程 → 推送到 GitHub。

## 内容

| 文件 | 说明 |
|---|---|
| `README.md` | 本文件，仓库说明 |
| `Git速查表.md` | Git 日常命令速查，含本机踩坑记录 |
| `demo-hello/` | 克隆的练习仓库（已忽略，不纳入版本管理） |

## 我已经学会的

- [x] `git clone` 克隆别人的仓库
- [x] `status` / `diff` 看懂当前状态
- [x] `add` / `commit` 提交改动
- [x] `restore` 丢弃误改
- [x] `switch -c` 开分支、`merge` 合并
- [x] `fetch` / `pull` 区分
- [x] `push` 推送到自己的仓库（2026-11-01 首次推送成功）

## 常用命令

```bash
git status                        # 我现在在哪
git add .                         # 把改动加入暂存区
git commit -m "feat: 做了什么"    # 存档
git push                          # 上传
```
